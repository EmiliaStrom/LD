# Labvanced Implementation Checklist

## 1. Study requirements

- [ ] Study protocol and experimental design reviewed
- [ ] Conditions, participant groups, and outcome measures defined
- [ ] Stimuli and instructions collected
- [ ] Required data variables documented

## 2. Labvanced study setup

- [ ] Study created and named consistently
- [ ] Tasks, blocks, sessions, and groups configured
- [ ] Participant flow implemented
- [ ] Study settings and device requirements configured

## 3. Task implementation

- [ ] Frames and visual elements created
- [ ] Stimuli uploaded and displayed correctly
- [ ] Events and triggers implemented
- [ ] Response handling and feedback tested
- [ ] Randomization and counterbalancing implemented

## 4. Variables and data recording

- [ ] Variables use consistent naming conventions
- [ ] Variable types and reset behavior verified
- [ ] Response accuracy and reaction time recorded where required
- [ ] All required variables enabled for recording

## 5. Testing and quality assurance

- [ ] Complete participant journey tested
- [ ] All experimental conditions tested
- [ ] Incorrect and missing responses tested
- [ ] Randomization verified across multiple runs
- [ ] Browser and device compatibility tested
- [ ] Test data exported and checked

## 6. Launch and handover

- [ ] Researcher approval obtained
- [ ] Final study version documented
- [ ] Data recordings activated
- [ ] Published participation link tested
- [ ] Handover and support notes documented
